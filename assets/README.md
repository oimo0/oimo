# Logo assets

このフォルダには、oimoサイトで使用するASROグループのロゴ画像を配置します。

現在はダミーのSVGロゴを置いています。実際のロゴPNGが用意できたら、同名のファイルをアップロードして置き換えてください。

## ファイル対応表

- `asro-logo.svg` → ASRO親ブランドの文字ロゴ
- `asro-ai-logo.svg` → ASRO AIの文字ロゴ
- `asro-hub-logo.svg` → ASRO Hubの文字ロゴ
- `asro-i-logo.svg` → ASRO-iの文字ロゴ
- `asra-logo.svg` → Asra文字ロゴ
- `asra-icon.svg` → Asraシンボルロゴ（山形＋青い丸）

## 実ロゴへの差し替え

1. `assets`フォルダを開く
2. **Add file** → **Upload files**を選択
3. PNGをアップロードする（例: `asra-icon.png`）
4. `index.html`内の画像パスの拡張子を`.svg`から`.png`に変更する

透明背景PNGがおすすめです。
